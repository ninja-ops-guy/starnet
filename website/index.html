What it is

AeroTech Staff is a local-first AI workstation. You run it as a desktop app, it spawns a small server on your own machine, and your agents live and work right there. You steer them in real time, watch them move through a station, and intervene when you want to. It's a game layer over real agent work.

Your own machine

Everything runs locally. Conversations, memories, files, and agent state live in a workspace on your disk, not in someone else's cloud.

Real agents, real work

Agents can send messages, fetch web pages, read and write files, run code, and use the tools you give them. You watch it happen and step in when you want.

BYOK or Credits

Plug in your own API keys and pay your provider directly, or buy AeroTech Staff Credits and let us handle the billing. Both paths work; neither is required.

Desktop-native

A real native window, system tray, auto-start, update checks, and OS keychain storage for your keys. Not a browser tab.

Chat channels

Connect Discord, Telegram, Slack, Matrix, or Signal and let your agents read and write channels. They can work while you're away.

Open source

MIT-licensed. You can read the code, fork it, and run your own build. The source is the spec.

How it works

AeroTech Staff is a Tauri desktop shell around a Node.js sidecar. The shell spawns the sidecar on a private loopback port, waits for it to be ready, and opens it in a native WebView2 (or WKWebView / WebKitGTK) window. The sidecar does the agent work; the shell handles the native desktop integration.

You don't need to know any of that to use it. Download, install, add a key, and start a station.
